What are agent skills? A plain-English guide for bot owners

An agent skill is a small file that teaches an AI bot how to do one job your way, every time. Here is what’s inside one, how bots use them, which tools read them, and how I check a skill before I trust it.

What is an agent skill, in one paragraph?

An agent skill is a folder with a SKILL.md file in it. The file has a short header with a name and a description, then plain instructions: when to use the skill, the steps, and the rules. An AI bot keeps the descriptions of all its skills in mind. When your request matches one, it loads the full file and follows it. You write the instructions once, and the bot reuses them in every later chat.

The format was published by Anthropic in October 2025, made an open standard that December, and in October 2026 handed to the Agentic AI Foundation under the Linux Foundation. Anthropic says more than 70 agent platforms have built it in. That shared format is why one skill can work across many bots, and it’s why I write every skill I publish to it.

What’s inside a skill?

PartRequired?What it’s for
SKILL.md header: nameYesThe skill’s ID, in lowercase with hyphens, matching the folder name
SKILL.md header: descriptionYesWhat it does and when to use it. The bot uses this to decide when to load the skill.
SKILL.md bodyYes, in practiceSteps, examples, output format, and rules
scripts/NoCode the bot can run. Read it before you allow that.
references/NoLonger documents the bot reads only when needed
assets/NoTemplates, images, or data files

Everyday skills usually need only the SKILL.md. If you want to write one, start with my annotated SKILL.md template.

How does a bot use a skill?

  1. At the start, the bot reads only the name and description of each skill it has. That’s cheap, so a bot can carry many skills.
  2. When a request matches a description, the bot loads the full SKILL.md and follows it.
  3. If the skill points to other files, the bot opens them only when the task needs them.

This is why a vague description is the most common reason a skill “doesn’t work.” If the description doesn’t contain the words you actually use, the bot never loads the rest.

How are skills different from prompts, instructions, and MCP?

ThingWhat it isWhen it applies
PromptA message you typeThat one chat
Custom or standing instructionsA block of text saved in the bot’s settingsEvery chat, always
Agent skill (SKILL.md)A file of instructions for one jobWhen a request matches its description
Routine or scheduled taskA saved job that runs at a set timeOn a schedule, often using a skill for the “how”
MCP server or connectorA bridge that gives the bot access to another app or data sourceWhenever the bot needs that app
AGENTS.md or CLAUDE.mdA file of project instructions for coding agentsWhen the agent works in that project

A simple way to remember it: a connector gives a bot access, a skill gives it know-how, and a routine gives it a schedule. They work together. A daily reminder, for example, is a routine that runs a reminder skill.

Which AI tools read agent skills?

Tools whose own documentation, as of November 23, 2026, says they read SKILL.md skills include Claude Code, the Claude apps and API, Codex, Cursor, GitHub Copilot, VS Code, Gemini CLI, OpenCode, goose, and Amp. ChatGPT has a skills feature, with access depending on your plan. Grok Bot saves skills in the app and stores them as SKILL.md files. OpenClaw has its own skill registry.

The shared part is the file: the two header fields and the instructions. The parts that differ are where the folder goes (many tools scan .agents/skills, and Claude Code uses .claude/skills), how you switch a skill on, and what permissions a skill gets. Support changes often, so check your tool’s current docs. My compatibility table sums up the main kinds of tool.

Are agent skills safe?

A skill is safe as long as its instructions are, and you can’t tell that from the name. Skills are instructions a bot follows, so a careless or malicious one can tell a bot to send messages, spend money, run code from the internet, or follow orders hidden in a web page. In an early-2026 study, Snyk scanned 3,984 skills from two public skill directories and found at least one critical security issue in 13.4% of them.

Before I install any skill, mine included, I check five things:

  1. Read it all. If you can’t follow what it tells the bot to do, don’t install it.
  2. Look for an ask-before-acting section. Anything that sends, spends, deletes, or handles passwords should need your OK first.
  3. Look for hidden text. Invisible characters, comments, or lines like “don’t tell the user” are red flags.
  4. Check scripts and links. Know what any script does and where every link goes.
  5. Keep your platform’s controls on. Approval prompts and spending limits in your AI tool are the real safeguard. A skill only adds to them.

FAQ

Are agent skills the same as prompts?

No. A prompt is something you type once in a chat. A skill is a saved file the bot can load again on later runs, whenever a request matches its description. That makes skills better for anything you want done the same way every time.

Do I need to know how to code to use a skill?

No. Most everyday skills are plain English instructions. Some skills include scripts, which is where coding knowledge helps, mainly so you can check what a script does before a bot runs it.

Can a skill make my bot do something I didn't ask for?

It can try. A skill is instructions the bot follows, so a badly written or malicious skill can push a bot to send, spend, or share things. Read a skill before you install it, run it through a checker, and keep your platform’s own approval settings on.

Will a skill I write for one AI tool work in another?

Often, yes, if it sticks to the name and description fields and plain instructions. The file format is shared. Where the file goes and how you switch it on differ by tool.
