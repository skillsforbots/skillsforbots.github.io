What it does

I wrote this skill for people working toward a score-sensitive goal who want a clear daily plan and will do the sending and paying themselves. Each run starts with the disclaimer, then lists today’s top 3 actions. Every impact figure is labeled as an estimate.

The bot drafts dispute and goodwill letters for your review. It never sends letters, files disputes, calls anyone, opens accounts, or pays anything.

Who it’s for

People who want a structured, educational daily brief on the usual credit levers and prefer to make every move themselves. If you want to see the approach first, read the free guide on getting a daily credit action plan from Grok Bot.

What’s included

  • credit-repair-coach/SKILL.md: the coach skill for a daily or on-demand brief
  • Topic notes on the main levers: utilization timed to statement dates, disputing inaccurate items, goodwill letters, pay-for-delete caveats, authorized-user tradelines, rapid rescore, avoiding new hard inquiries, and reading score factors
  • A fixed brief format: today’s top 3 actions, each with an impact range labeled as an estimate
  • Dispute and goodwill letter drafts for your review
  • A copy-paste coach bot description, routine prompt, and optional first-run intake
  • A required disclaimer on every run
  • README.md: a five-minute setup guide

It works with any bot that accepts skill or instruction files, including Grok Bot.

How to add it to Grok Bot

  1. Buy and download the .zip, then unzip it.
  2. Open each SKILL.md and replace the [BRACKET] placeholders with your own details.
  3. Paste the skill into a Grok Bot chat and ask the bot to save it as a private skill, or add it as standing instructions in any assistant that accepts skill or instruction files. Private skills are one library shared by all your Grok Bots; if a bot can’t find this one, open Connect apps in the sidebar, select the connected count next to the title, and turn it on under Private skills.
  4. Follow the README to set up the routine, then test it on something low-stakes.
