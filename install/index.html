How to add a skill to any AI bot

Skills use one shared format, but every AI tool takes them in a different way. Some read a folder on your computer, some want an upload, and some want you to ask in chat. Here are the steps that work everywhere, and a guide for each tool.

The five steps that work everywhere

  1. Get the skill folder. Download or copy the folder that holds the SKILL.md. Keep the folder name the same as the skill’s name.
  2. Read it and fill it in. Read the whole file and any scripts. Replace every [BRACKET] placeholder with your details.
  3. Put it where your tool looks. Folder-based tools read a skills folder on your computer. App-based tools take an upload or a chat request. The table below lists each one.
  4. Confirm the tool found it. Ask the bot which skills it can use, or check the tool’s skills list.
  5. Test it on something harmless. Make a request that matches the description. If the skill can send or spend, check that the bot stops and asks first.

Folder tools vs app tools

Folder tools

Coding agents such as Claude Code, Codex, Cursor, GitHub Copilot, and Gemini CLI read skills from folders. You copy the skill folder into the right place, and the tool picks it up, often without a restart. The neutral .agents/skills/ folder works in most of them, and a project folder can be committed to a repo so everyone on the project gets the same skills.

mkdir -p ~/.agents/skills/reminder-basics
cp SKILL.md ~/.agents/skills/reminder-basics/

App tools

Chat assistants keep skills in your account instead. The Claude apps take a ZIP upload. ChatGPT has a Skills tab where you create with chat, use an editor, or upload. Grok Bot keeps a private skill library shared by all your bots, and you add to it by asking the bot to save a skill. These skills follow your account across devices, but they don’t sync to the folder tools. A skill on claude.ai, for example, isn’t in Claude Code on your laptop.

How to confirm a skill loaded

In any tool, ask two questions in a new chat:

Which skills can you use right now?
If I asked you to use [skill name], what would you do first?

The bot should list the skill and describe its first step in its own words. Then run a real request that matches the description. If nothing happens:

  • Check the name. The folder name and the name field should match, in lowercase with hyphens.
  • Check the header. A broken YAML header can stop a tool from matching your description. My SKILL.md checker catches the common mistakes.
  • Ask for it by name. Use /name in Claude Code and Cursor, $name in Codex, @ in ChatGPT, or ask Grok Bot for the skill by name.
  • Sharpen the description. It’s what the tool matches on. Say what the skill does and when to use it.

Using one skill in several tools

Keep one master copy. Put it in ~/.agents/skills/ for the folder tools, symlink it into ~/.claude/skills/ for Claude Code, and upload or paste the same file into the app tools. When you change it, update the app copies too, since they don’t follow the folder.

Stick to the portable parts: name, description, and plain instructions. Tool-specific header fields may be ignored elsewhere. And repeat your safety rules in the skill itself, because each tool’s approval settings are different. My approval rules template is written to paste into any skill.

FAQ

How do I install an agent skill?

Get the skill folder, read it and fill in any placeholders, put it where your tool looks (a skills folder, an upload, or a chat request), confirm the tool lists it, and test it on something harmless.

Is there one folder every AI tool reads?

Not every tool, but .agents/skills/ in a project or ~/.agents/skills/ in your home folder is read by most folder-based tools. Claude Code reads .claude/skills/ instead, and app-based assistants use an upload or a chat request.

Do I need to code to install a skill?

No. App tools take an upload or a pasted file. Folder tools need only a copy into the right folder. Read any scripts a skill includes before letting a bot run them.

Why won’t my bot use the skill I installed?

Usually the name doesn’t match the folder, the header is broken, or the description is too vague to match your request. Ask for the skill by name, then fix the description.
