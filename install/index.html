Grok Bot skill install hub: every way to add, enable, and share a skill

Grok Bot keeps your skills in one private library that all your Bots share. There are several ways to get a skill into it, and a couple of settings decide which Bot can use it and who else can. This page puts them all in one place, with links to the step-by-step guides.

The five steps for any skill

  1. Pick a method. Save a task you have just done, teach it by demonstration, or paste a SKILL.md someone else wrote. The table below compares them.
  2. Read it and fill it in. Read the whole file and any scripts. Replace every [BRACKET] placeholder with your details.
  3. Ask the Bot to save it as a private skill. Private skills are one library shared by all your Bots, so you add each skill once.
  4. Turn it on if a Bot can’t find it. Open Connect apps in the sidebar, select the connected count next to the title, and enable the skill for that Bot under Private skills.
  5. Test it on something harmless. Ask for the skill by name, or make a request that matches its description. If the skill can send or spend, check that the Bot stops and asks first.

Turn a skill on for a Bot

The Grok Bot docs say skills are available across your Bots, although a Bot may need the relevant app or login to use one. If a Bot says it can’t find a skill:

  1. Open Connect apps in the sidebar.
  2. Select the connected count next to the title.
  3. Under Private skills, enable the skill for the current Bot.

If the skill needs an app, such as a calendar, connect that app too. A skill gives a Bot know-how, not access. My guide to agent skills vs MCP servers explains the difference.

Share a skill with your team

If you belong to a team, you can publish a private skill so your teammates can use it.

  1. On desktop, open Connect apps, select the connected count next to the title, and open the skill.
  2. Choose Publish in its header. If you belong to more than one team, choose the team under Publish to.

A skill needs a description before you can publish it, because teammates and their Bots use the description to decide when it applies. After you publish, the menu offers Sync, to push your later edits to the team’s copy, plus Copy link and Unpublish. Publishing can be refused if you aren’t on a team yet, or if your admin has turned it off for members. Skills that came with the app or with a Bot’s template can’t be published.

Before you publish, check that the skill doesn’t name your own people, channels, or accounts. A teammate’s Bot would follow those instructions too.

How to confirm a skill loaded

Ask your Bot two questions in a new chat:

Which skills can you use right now?
If I asked you to use [skill name], what would you do first?

The Bot should name the skill and describe its first step in its own words. Then run a real request that matches the description. If nothing happens:

  • Check it’s turned on. Look under Private skills in Connect apps for that Bot.
  • Ask for it by name. The Grok Bot docs say to ask the Bot for a skill by name.
  • Check the header. A broken YAML header can stop the description from matching. My SKILL.md checker catches the common mistakes.
  • Sharpen the description. It’s what the Bot matches on. Say what the skill does and when to use it.

A good first skill to practice with

Pick something harmless, with a result you can see. My free Reminder Basics skill is a good one: it sets up one daily reminder that keeps coming back until you say it’s done, and it never messages anyone else. The Bot Safety Rules Starter is the one I add to every bot before anything else.

FAQ

How do I add a skill to Grok Bot?

Do the task once and ask the Bot to save the process as a skill, use Teach a task to show it a browser workflow, or paste a SKILL.md and ask the Bot to save it as a private skill. Then test it on something harmless.

Do I have to add a skill to each of my Bots?

No. The Grok Bot docs say private skills are one library shared by all your Bots. If a Bot can’t find one, open Connect apps, select the connected count next to the title, and enable it for that Bot under Private skills.

Can I share a skill with my team?

Yes, if you belong to a team. On desktop, open the skill from Connect apps and choose Publish. It needs a description first. Skills that came with the app or with a Bot’s template can’t be published.

Why won’t my Bot use the skill I added?

Usually it isn’t turned on for that Bot, the header is broken, or the description is too vague to match your request. Check Private skills, ask for the skill by name, then fix the description.
