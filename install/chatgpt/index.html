What a ChatGPT skill is

OpenAI’s help center describes skills as reusable, shareable workflows that help ChatGPT complete specific tasks more consistently. A skill can include instructions, examples, and code. Once a skill is installed, ChatGPT can use one or more skills on its own when they help.

OpenAI’s developer docs say skills build on the open agent skills standard. That means the same basic layout used elsewhere: a folder with a SKILL.md that has a name and description, plus optional scripts and references. ChatGPT starts with each skill’s name and description and loads the full instructions when it decides to use that skill.

Who can use skills in ChatGPT?

Availability depends on plan, workspace settings, and app. On November 23, 2026, the help center said skills are available to eligible ChatGPT Business, Enterprise, Healthcare, and Edu users. OpenAI’s developer docs add that standalone skills work in the ChatGPT desktop app, Codex CLI, and the IDE extension, while skills bundled in plugins are also available in Chat and Work across ChatGPT on the web, desktop, and mobile.

In practice: if you see a Skills tab under Plugins in the sidebar, you have access. In a managed workspace, an admin controls who can create, upload, share, publish, and install skills.

How to add a skill

  1. Open the Skills tab. In the ChatGPT sidebar, select Plugins, then the Skills tab in the Plugin Directory.
  2. Choose how to create it. Select Create, then Create with chat, Create with editor, or Upload from your computer.
  3. Upload or describe the skill. To upload, choose a skill folder you’ve read and trust. To create with chat, describe the job and answer ChatGPT’s follow-up questions.
  4. Wait for the scan. ChatGPT scans uploaded skills. Most are available right after. Some are marked Needs Review, and risky ones can be Blocked.
  5. Use it. Type @ in a chat to pick the skill, or just ask for the job and let ChatGPT choose it from the description.

Eligible accounts come with a built-in skill-creator skill. When you ask ChatGPT to create or change a skill, it uses that to draft, update, or fix it. “Create with chat” is the easiest route if you’ve never written a skill.

Uploading a skill from GitHub

Most skills on GitHub are a folder with a SKILL.md. To upload one:

  1. Download the skill folder. On GitHub, the simplest way is to download the whole repo as a ZIP and keep just the folder you want.
  2. Read the SKILL.md and any scripts. OpenAI’s own advice is to review a skill, especially one from an outside source, and make sure you trust it.
  3. Fill in any [BRACKET] placeholders.
  4. Upload it through Create, Upload from your computer.

The upload scan helps, but OpenAI says it shouldn’t replace your own review. My skill safety check takes about five minutes, and my SKILL.md checker runs in your browser without uploading anything.

How to use a skill

  • By name: type @ in a chat and pick the skill.
  • Automatically: ask for the job. ChatGPT picks a skill when your request matches its description. OpenAI advises front-loading the main use case and trigger words in the description, in case descriptions are shortened.
  • On a schedule: pair the skill with a scheduled task, such as “Every Sunday at 6 PM, use weekly-plan.” See skills vs scheduled tasks.

To share a skill in a workspace, open the skill’s more options menu (•••) on the Skills page and select Share.

Four everyday skill ideas

These are short enough to create with chat. Paste the description, then add your own details. Each one keeps the risky step, such as sending or buying, behind your yes.

Skill nameWhat to tell ChatGPT it does
inbox-draftsSort new email into reply, read later, and ignore. Draft replies in my tone for the first group. Never send. Show me the drafts as a list.
weekly-planEvery Sunday, turn my notes and calendar into a one-page plan for the week: three priorities, appointments, and anything due. Flag clashes. Don’t accept or decline invites.
packing-listBuild a packing list from the trip length, weather forecast, and activities I name. Group by bag. Ask before adding anything I’d need to buy.
receipt-logWhen I paste a receipt, extract store, date, total, and category into a table row. Mark anything unclear as Unknown rather than guessing.

ChatGPT, Codex, and plugins

OpenAI uses one skills format for ChatGPT and Codex. Skills are how you write a workflow. Plugins are how you share it: a plugin can include skills, apps, or both, and plugins appear in a directory shared by ChatGPT and Codex.

If you work in Codex, skills live in folders on your machine rather than in the ChatGPT Skills tab. My guide to the Codex skills location covers the paths.

FAQ

Does ChatGPT support skills?

Yes. OpenAI’s help center describes skills as reusable workflows ChatGPT can use automatically when they help. Availability depends on your plan and workspace settings.

Can I upload a SKILL.md to ChatGPT?

Yes, if you have access to skills. Go to Plugins, Skills, select Create, then Upload from your computer. ChatGPT scans the skill before it becomes available.

How do I use a skill in ChatGPT?

Type @ in a chat and pick it, or ask for the job and let ChatGPT choose the skill from its description.

Are ChatGPT skills the same as Codex skills?

They use the same format, which builds on the open agent skills standard. Codex reads skills from folders on your machine, while ChatGPT manages them in the Skills tab.
