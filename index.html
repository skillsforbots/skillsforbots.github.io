Skills for Bots

Ready-to-run skill templates for Grok Bot and similar AI agents.

A skill is a SKILL.md file: standing instructions, rules, and copy-paste prompts that a Grok Bot or similar AI assistant follows so it behaves the same way every time. You fill in the placeholders, add the file to your bot, and it uses those instructions on later runs instead of relying on a one-off chat.

Free skills

Bot Safety Rules Starter

Standing safety rules for any bot: no sending email or messages without owner approval, no spending money, and a one-time “send this” or “pay this” is approval for that item only, not a standing waiver. Includes a blank structured handoff note so work can move between bots without dropping context. MIT-licensed, with a five-minute install guide, in the grok-bot-skills repository.

Also on Agensi: Bot Safety Rules Starter.

Reminder Basics

One reminder that comes back every day until you clearly say it’s done. “Thanks,” “ok,” and “I’m working on it” don’t stop it; “done” does. Free version: one item and one daily time. The full Nag-Until-Cleared Reminders pack below adds a list, other schedules, and chat commands.

Also on Agensi: Reminder Basics.

Usage Reset Sprint

Use leftover usage on a project right before a usage or token limit resets: check remaining usage and the reset time, finish the highest-value chunk that fits, and leave a handoff so work can resume after the reset. The bot does not buy credits, spend money, or send messages to get more usage. The Project Sprint pack below adds multi-day planning, handoff templates, a resume-after-reset routine, a weekly project review, and a usage budget check.

Also on Agensi: Usage Reset Sprint.
