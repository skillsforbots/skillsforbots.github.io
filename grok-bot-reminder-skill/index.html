What it does

I wrote this skill because calendar pings get swiped away and the thing still isn’t done. I use it on my own bots. The bot keeps one list, sends every open item when the routine fires, and only takes an item off when you clearly say to clear it.

“Thanks,” “ok,” “I’m on it,” and “later” keep the item open. “Done” or “clear it” takes it off. If a reply is unclear, the bot asks.

Who it’s for

People who use a Grok Bot or another assistant with scheduled routines and keep dropping the slow-burn to-dos: renewals, forms, appointments to book, paperwork to send back. If one item on one daily time is enough, start with the free Reminder Basics skill on GitHub instead.

How to add it to Grok Bot

FAQ

Does replying “ok” or “thanks” clear a reminder?

No. Only a clear “done,” “clear it,” or “take it off the list” clears an item. “Thanks,” “ok,” “I’m on it,” and “later” keep it open.

How is this different from the free Reminder Basics skill?

Reminder Basics handles one item on one daily time. This pack keeps a whole list on one reminder, adds other schedules, and adds chat commands to add, edit, clear, pause, or show items.

What do I need to use it?

A Grok Bot or any assistant that accepts skill or instruction files and supports scheduled routines.

Will the bot do the task for me?

No. The skill tells the bot to remind you, not to do the task, unless you ask it to.
