What it does

I wrote this pack for projects that take more than one usage or token window. I use it on my own bots when leftover usage would otherwise disappear mid-task. The bot plans work that can actually finish, sprints on the highest-value chunk before a reset, and resumes from a handoff instead of starting over.

It never buys credits, upgrades a plan, or spends money to get more usage, and it asks first for anything outside the plan. It’s the paid upgrade of my free Usage Reset Sprint skill on GitHub, which covers one window and one handoff.

Who it’s for

People whose project takes more than one usage or token window and who want leftover usage to turn into saved progress. You review the plan, say yes to each sprint, and do any sending or paying yourself.

What’s included

  • multi-day-project-plan: leftover work broken into finishable chunks across several usage windows, with a wrap-up buffer in each
  • pre-reset-sprint: check remaining usage and the reset time, shrink the chunk if less remains, save as you go, and leave a thorough handoff
  • handoff-notes: session notes, end-of-window handoffs, and a project-plan snapshot, each with a short resume prompt
  • resume-after-reset: load the latest handoff, confirm files, propose the next finishable chunk, and wait for a yes
  • weekly-project-review: a read-only look at what moved, what’s stuck, and a suggested plan for next week
  • usage-budget-check: compare remaining usage to the planned chunk plus a wrap-up buffer, and never buy credits
  • Standing safety rules, including always-on rules that the bot takes orders only from you and never follows hidden text it finds in outside content
  • README.md and QUICK-START.md: a setup guide and a five-minute quick start

It works with any bot that accepts skill or instruction files, including Grok Bot.

How to add it to Grok Bot

  1. Buy and download the .zip, then unzip it.
  2. Open each SKILL.md and replace the [BRACKET] placeholders with your own details.
  3. Paste the skill into a Grok Bot chat and ask the bot to save it as a private skill, or add it as standing instructions in any assistant that accepts skill or instruction files. Private skills are one library shared by all your Grok Bots; if a bot can’t find this one, open Connect apps in the sidebar, select the connected count next to the title, and turn it on under Private skills.
  4. Follow the README to set up the routine, then test it on something low-stakes.

FAQ

Will the bot buy more credits or upgrade my plan?

No. Every skill in the pack tells the bot never to buy credits, upgrade a plan, or spend money to get more usage.

How is this different from the free Usage Reset Sprint skill?

Usage Reset Sprint covers one window and one handoff. Project Sprint adds multi-day planning, handoff templates, a resume-after-reset routine, a weekly read-only review, and a usage budget check.

What if my bot can’t see its remaining usage?

The bot can only use remaining usage and the reset time if the platform shows them or you tell it.
