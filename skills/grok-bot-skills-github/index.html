How I picked and checked these

I searched GitHub for “grok bot skills” and “grokbot skills” on November 23, 2026 and kept repos that hold skills or skill-like templates for Grok Bot and are public. For each one I read the README and the license GitHub reports. I didn’t install every skill, so treat this as a map, not a review.

I left out star counts and rankings on purpose. Stars change daily and say little about whether a skill is safe or useful for you. The order below is loosely from everyday-use skills to developer and catalog repos, not a score.

If you’re new to all this, two pages help first: what agent skills are, and how to install a Grok Bot skill from GitHub.

Each repo, in a few lines

skillsforbots/grok-bot-skills

Mine. Three instruction-only everyday skills: the Bot Safety Rules Starter (no sending or spending without approval, outside content treated as information), Reminder Basics (one reminder that repeats until you say done), and Usage Reset Sprint (use leftover usage before a limit resets).

Install: Paste the SKILL.md and ask the bot to save it, or add it as standing instructions. License: MIT.

ofershap/grok-bot-skills

A community library where each skill is one SKILL.md. The catalog includes writing and thinking skills such as short-answers, morning-brief, monthly-checkpoint, claim-check, and source-audit. The README says Grok bot skill loaders haven’t been tested in that repo.

Install: A copy-paste install prompt for the bot, or npx skills add for other agents. License: MIT.

d-gangz/grokbot-skills

Skills for running a team of bots: design-bots, bot-audit, and bot-retro, plus a glossary and people store, a grilling interview skill, and skill-porter, which copies skills from other repos.

Install: A one-line message asking the bot to install a folder into your private skill library. License: None shown by GitHub.

bostonaholic/grokbot-skills

Grok Bot skills covering routines, workflows, and agent practices, one folder per skill.

Install: A message asking the bot to install from the repo using its AGENTS.md, or a shell script that copies the folders. License: None shown by GitHub.

stealth-factory/grok-bot-skills

Two developer skills: grok-bot-platform (how bots, groups, and webhook wakes work) and grok-bot-ui (a custom interface that talks to a host bot).

Install: npx skills add. License: MIT.

jaskirat1616/grok-skills

A large catalog. The README says 195 SKILL.md playbooks, gathered from open-source skill repos and contributions, with a browsable site.

Install: A marketplace command or a folder copy, as the README describes. License: MIT for the repo; each skill keeps its own license.

botkitsdev/botkits

The README lists 32 skills for writing, design, search, video, and bot upkeep, such as a routine health check and a transcript health check.

Install: npx skills add, or for Grok Bot, paste the SKILL.md and ask the bot to save it. License: MIT.

cobusgreyling/grok-bot-templates

Mostly bot templates (profiles) rather than single skills, with a spec, teams, skills, and routines.

Install: Paste a profile into the bot’s profile editor, per the README. License: MIT.

mergisi/awesome-grokbot

A curated list of copy-paste bot profiles, skills, and team templates.

Install: Copy and paste, per the README. License: CC0-1.0.

Bigibyte/awesome-grok-bot

A beginner guide and curated links for the Grok Bot app: bots, routines, skills, the cloud computer, and apps.

Install: It’s a reading list, not an installer. License: CC0-1.0.

jeremybrasher/grokbot-skills

A collection reshaped for Grok Bot from a public skills directory, with a source file pointing to each original.

Install: Copy one skill folder at a time, per the README. License: None shown at repo level; each skill keeps its original license.

Which one should I start with?

  • You want your bot to stop sending or spending on its own: start with a safety skill. Mine is the Bot Safety Rules Starter, and my approval rules template explains the rules line by line.
  • You run several bots: look at the team skills in d-gangz/grokbot-skills, and my guide to coordinating multiple Grok Bots.
  • You want better replies and research: ofershap/grok-bot-skills has short-answer, claim-check, and source-audit skills.
  • You want to browse a lot: the big catalogs, jaskirat1616/grok-skills and botkitsdev/botkits, are good for ideas. Read each skill before you install it, since they gather from many authors.
  • You build tools: stealth-factory/grok-bot-skills covers how bots and webhooks fit together.

For everyday life admin specifically, such as reminders, money guardrails, and usage resets, I keep a separate list: best agent skills for everyday life admin.

Before you install anything from a repo

A skill is text your bot follows, so a careless or hostile one can push a bot to send, spend, or share things. A security study by Snyk scanned 3,984 published agent skills from two big skill directories and reported that 13.4% had at least one critical-level issue. That study wasn’t about the repos above, but the lesson carries over. My routine takes about five minutes:

  1. Read the whole SKILL.md, not just the README.
  2. Search it for send, post, buy, pay, delete, password, and key. Each one should come with an “ask me first” rule.
  3. Open every script before letting the bot run it.
  4. Paste the file into my free SKILL.md checker. It runs in your browser and flags risky wording and hidden text.
  5. Test the skill on something harmless first.

The full checklist is in how to check a Grok Bot skill is safe before you install it.

Repos I left out, and how to suggest one

I skipped repos that are single-purpose tools rather than skill collections, forks with no changes of their own, and repos built around trading or acting without approval. Plenty of good single-skill repos exist too, and I’ll add the useful ones as I find them.

If you maintain a Grok Bot skill repo and think it belongs here, open an issue on my grok-bot-skills repo with a link. I check each suggestion the same way, and I don’t accept payment for placement.

FAQ

Are Grok Bot skills on GitHub free?

The repos on this page are free to read. Whether you may copy and reuse a skill depends on its license. Most here use MIT or CC0. A few have no license shown, so ask the author before reusing those.

Do skills from GitHub work in Grok Bot?

Most use the open Agent Skills format, a folder with a SKILL.md file, which Grok Bot can save as a private skill. Some repos say their skills haven’t been tested in Grok Bot, so test one on a harmless task first.

Which Grok Bot skill repo is the best?

There isn’t one best repo. Pick by job: a safety skill first if your bot can send or spend, team skills if you run several bots, and a big catalog when you want to browse ideas.

Why don’t you list star counts?

Stars change every day and don’t show whether a skill is safe or useful. I list what each repo is for, how it installs, and its license, as I read them on the day I checked.
