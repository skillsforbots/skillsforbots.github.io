How to add a skill to Grok Bot

A one-off prompt fades. A skill is a standing instruction file the bot follows on later runs. Here's how to add one in about five minutes.

A one-off prompt works until the next new chat, when you have to explain the same rules again. A skill is a standing instruction file the bot keeps and follows on later runs, so the behavior stays the same.

What a skill is

A skill is a SKILL.md file: standing instructions, rules, and copy-paste prompts. You fill in the placeholders, add the file to your Grok Bot or a similar assistant, and the bot uses those instructions on later runs instead of relying on one chat.

It is still just text the bot is told to follow. It is not a hard technical lock, and it is not a managed service. That's why the last step is always a test.

Why a chat prompt isn't enough

You can tell a bot "always ask before you send email," and it may do that in the same thread. Start a new conversation, or give the work to a second bot, and the rule is often gone. Standing instructions, or a saved skill, travel with the bot. That's the difference.

Add one in about five minutes

  1. Open the SKILL.md file for the skill you want to use.
  2. Replace every [BRACKET] placeholder with your details. Don't leave brackets in the text you paste. If a field doesn't apply, follow the file's instructions, which usually means writing None or Unknown rather than inventing something.
  3. Add it to the bot. Paste the bot description block into your Grok Bot as standing instructions, or paste the SKILL.md and ask the Bot to save it as a private skill.
  4. Test it with a request that should trigger the skill, and check that the bot follows the rules.

Free tip: confirm the skill actually loaded

After you add it, ask:

What standing rules are you following right now?
If I asked you to send an email, what would you do first?

The bot should recap the rules in its own words and, if a no-send rule is in place, say it would draft the message and wait. If it can't recap the rules, the skill didn't take. Paste the description again, or check that you added it to the bot you are chatting with.

A few things that go wrong

  • Placeholders left in. A bot that still sees [APPROVAL CHANNEL] may guess, or skip the step. Fill every bracket before you paste.
  • The rule lives in one chat only. If you pasted it as a message instead of as standing instructions or a loaded skill file, it may not be there next time.
  • Only one bot has the skill. If you run more than one assistant, add the same safety rules to each, or a handoff can skip them. There's a separate guide on coordinating multiple Grok Bots.
